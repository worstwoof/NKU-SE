3) 层定位：static / relative / absolute / fixed / sticky

relative 相对自身原位偏移；absolute 脱离文档流并相对最近的定位父级。

5) 绝对定位实现水平 + 垂直居中

left:50% + 负 margin（宽/高一半）
.center-box {
  position: absolute;
  left: 50%; top: 50%;
  width: 200px; height: 80px;
  margin-left: -100px; /* 宽度一半 */
  margin-top:  -40px; /* 高度一半 */
}
