# NKU-SE

南开大学软件工程相关课程资料整理。

## 目录结构

本仓库按课程分类整理大二下学期的学习资料：

- `java/`：Java 课程实验与报告资料
- `数据库/`：数据库课程课件与实验资料
- `机器学习导论/`：机器学习导论课件、实验与作业资料
- `毛泽东思想概论/`：毛泽东思想概论课程资料、期末复习资料与历年资料
- `算法导论/`：算法导论课程课件
- `计算机组成原理/`：计算机组成原理课程课件
- `设计思维/`：设计思维课程课件与作业资料

## 内容说明

仓库中主要包含：

- 课程 PPT、PDF 课件
- 实验文档与作业文件
- 复习资料、学习笔记与历年题
- 部分课程相关图片、压缩包和代码/Notebook 文件

## 使用方式

可以直接在 GitHub 页面浏览目录，也可以克隆到本地：

```bash
git clone https://github.com/worstwoof/NKU-SE.git
```

## 备注

资料仅用于课程学习、复习和个人整理。如有内容需要更新或补充，可以继续提交到对应课程目录。
